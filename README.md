# CS 210 Project Three: Corner Grocer

## Project Summary
This project is a grocery tracking program written in C++. It reads a file of items purchased during the day and counts how often each item appears. The program allows the user to search for a specific item, display all item frequencies, and view a histogram. This helps analyze which items are purchased most often.

## What I Did Well
I created a clear and user-friendly menu system. I also successfully read data from a file and displayed it in different formats, including a histogram.

## Where I Could Improve
I could improve my program by adding better input validation and error handling. This would make the program more reliable and secure.

## Most Challenging Part
The most challenging part was reading from the file and counting how often each item appeared. I overcame this by breaking the problem into smaller steps and using maps.

## Transferable Skills
This project helped me develop skills in file handling, data structures, and organizing code. These skills can be used in many future programming projects.

## Maintainability, Readability, and Adaptability
I used clear variable names, comments, and structured code to make the program easy to read and maintain. The program is adaptable because it reads from an input file, so it can work with different data.



# Module Eight Journal Reflection

## How do I interpret user needs and implement them into a program? How does creating user stories help with this?

I interpret user needs by understanding what the customer wants the program to do. User stories help describe each feature from the user's point of view. They make it easier to organize work, prioritize tasks, and make sure the final program meets the customer's needs.

## How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

I develop programs by breaking large problems into smaller tasks. I like to plan my work before writing code and test my code often. In the future, I hope to continue using Agile practices such as sprint planning, maintaining a product backlog, sprint reviews, and retrospectives because they help organize work and improve the final product.

## What does it mean to be a good team member in software development?

A good team member communicates clearly, works well with others, accepts feedback, and completes assigned tasks on time. Good teamwork helps solve problems faster and leads to better software. This course taught me that communication and collaboration are essential for successful software development.
